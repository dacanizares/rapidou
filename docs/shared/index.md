# Shared context

Every coding agent reads:

1. [Application principles](principles.md)
2. [Project structure](structure.md)
3. [Testing philosophy](testing.md)
4. The relevant file under [specifications](../specs/index.md)

Keep code plain, direct, and complete. Prefer functions, structs, explicit control flow, plain SQL, browser primitives, and functional tests. Avoid new layers, frameworks, dependencies, and ceremonies unless the current requirement needs them.
