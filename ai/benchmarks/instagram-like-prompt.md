# Instagram-like benchmark

Implement this application in `src/` of this isolated Rapidou checkout. Do not
change the benchmark runner, agent configuration, or this prompt. Work until the
application is complete and run the repository's functional test when practical.
In your final response, state what you implemented and whether tests passed.

Create an Instagram-like application with multiple users. Everyone can see
everyone else's photos. Seed it with Unsplash image URLs and invented profiles:
five seed profiles, ten photos per profile, so the application opens with content
already visible.

A registered user can give a thumbs-up to a post. An anonymous visitor who tries
to do so sees a login prompt. The visual style is clean and restrained.

Include comments and photo uploads. The five initial people are seed data only;
every newly registered user can upload more photos.
